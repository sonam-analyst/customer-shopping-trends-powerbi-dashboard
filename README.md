# customer-shopping-trends-powerbi-dashboard

## Project Overview

This project presents an interactive **Power BI dashboard** created using the **Customer Shopping Trends 2023** dataset.

The dashboard provides insights into customer purchasing behavior, sales performance, product categories, customer ratings, shipping methods, locations, sizes, and payment methods.

## Key Analysis

The dashboard includes analysis of:

* Customer locations
* Average customer review ratings
* Purchase amount by size
* Purchase amount by item purchased
* Previous purchases
* Purchase amount by shipping type
* Payment methods
* Product and customer shopping trends

## Tools Used

* Power BI Desktop
* Power BI Data Visualization
* Customer Shopping Trends 2023 Dataset

##  Dashboard Highlights

The dashboard analyzes purchase amounts across different sizes, with **Medium (M)** having the highest purchase amount among the displayed sizes. It also provides item-level purchase analysis, where products such as Blouse, Shirt, Dress, and Pants are among the displayed items.

Shipping-type and payment-method analysis are also included to understand customer purchasing patterns across different transaction and delivery methods.

## Objective

The main objective of this project is to transform customer shopping data into meaningful visual insights that can support **data-driven business decisions**.
